# Quantumult X

## Lists

- [`Filters/filters_assigned.list`](Filters/filters_assigned.list) — 需要由使用者指定代理或策略的服務規則。
- [`Filters/filters_block.list`](Filters/filters_block.list) — 封鎖廣告、追蹤器及其他不需要連線的網域與 IP。
- [`Filters/filters_correction.list`](Filters/filters_correction.list) — 修正上游規則造成的錯誤封鎖。
- [`Filters/filters_direct.list`](Filters/filters_direct.list) — 必須直接連線的服務規則。
- [`Filters/filters_macau.list`](Filters/filters_macau.list) — 需要使用澳門網絡或澳門節點的服務規則。

## Rewrites

- [`Rewrite/Adrewrite.list`](Rewrite/Adrewrite.list) — 自行維護的廣告封鎖、拒絕及重新導向規則。
- [`Rewrite/Advertising.list`](Rewrite/Advertising.list) — 合併外部來源的廣告 URL Rewrite 規則。
- [`Rewrite/Bilibili/Bilibili.Enhance.list`](Rewrite/Bilibili/Bilibili.Enhance.list) — Bilibili 介面增強、功能調整及廣告移除。
- [`Rewrite/GeneralAdBlock/GeneralAdBlock.list`](Rewrite/GeneralAdBlock/GeneralAdBlock.list) — 移除各服務的廣告及推廣內容。
- [`Rewrite/Youtube/YouTube.Enhance.list`](Rewrite/Youtube/YouTube.Enhance.list) — YouTube 與 YouTube Music 功能增強、廣告移除及字幕／歌詞翻譯。
